# JEI Angklung
**Jawara Entertainment Indonesia**

JEI Angklung menghadirkan energi musik tradisional Indonesia dalam pertunjukan yang hangat, modern, dan tak terlupakan.

## Tentang

JEI Angklung adalah grup musik angklung di bawah naungan Jawara Entertainment Indonesia. Kami memadukan melodi angklung klasik dengan aransemen kontemporer untuk berbagai jenis acara:

- 🏢 Acara Korporat
- 🌍 Festival Budaya
- 💍 Pernikahan & Resepsi
- 🎓 Edukasi & Sekolah

## Struktur

```
index.html   # Halaman utama / landing page
style.css    # Tampilan visual
```

## Cara Menjalankan

Buka `index.html` langsung di browser, atau gunakan server lokal sederhana:

```bash
npx serve .
```
